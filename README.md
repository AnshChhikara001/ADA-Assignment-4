# Assignment 4 - Advanced Algorithmic Strategies

## 📌 Overview

This assignment focuses on solving complex real-world problems using advanced algorithmic techniques such as Backtracking, Branch and Bound, and String Matching. These approaches are commonly used in constraint satisfaction, optimization, and pattern detection problems.

---

## 📂 Tasks Covered

### 🔹 Task 1: Backtracking Algorithm

* Implemented N-Queens problem using recursion
* Applied constraint checking to ensure valid placements
* Demonstrated systematic exploration of solution space

---

### 🔹 Task 2: Branch and Bound Algorithm

* Implemented 0/1 Knapsack using Branch and Bound
* Used bounding function to prune unnecessary paths
* Improved efficiency compared to brute-force approach

---

### 🔹 Task 3: String Matching Algorithms

* Implemented:

  * Naive String Matching
  * KMP (Knuth-Morris-Pratt) Algorithm
* Counted number of character comparisons
* Compared efficiency of both methods

---

### 🔹 Task 4: Experimental Comparison

* Compared Naive and KMP algorithms for increasing text sizes
* Observed performance differences
* Analyzed scalability and efficiency

---

### 🔹 Task 5: Conceptual Programming

* Added detailed comments in code
* Explained logic of backtracking approach
* Improved code readability and understanding

## 📊 Observations

* Backtracking explores all possibilities but becomes slow for large inputs
* Branch and Bound improves efficiency by pruning non-optimal solutions
* Naive string matching performs more comparisons
* KMP is more efficient due to preprocessing (LPS array)
* Performance difference becomes significant as input size increases
